# 🧑‍💻 Personal Portfolio Website

This repository contains the source code for my personal portfolio website, built using Next.js. The website is designed to showcase my background, technical skills, and selected projects in a clean and professional way. It features a fully responsive layout, ensuring a seamless experience across various devices and screen sizes.

Through this portfolio, I aim to provide an overview of my expertise in software development, highlight my previous work, and offer an easy way for visitors or potential collaborators to get in touch. The project structure is organized for scalability and easy maintenance, making it straightforward to add or update content in the future.
